# FFmpeg 成片导出

## 输入

- 当前片段列表，按 `shot_no` 排序。
- 每个片段已采用的视频版本。
- 当前 Script 对应的 Dialogue。
- `subtitle_mode = none | en | bilingual`。

HTTP 接口只创建 `project_export` 后台任务并返回 `202 + GenerationTask`。创建任务时冻结
片段顺序、采用的视频版本、媒体 URI、实际时长、Dialogue 时间轴、项目分辨率和字幕模式；
排队期间的上游修改不会悄悄改变本次成片。

## 音频策略

每个视频先探测是否存在音轨：

- 有音轨：保留片段原生音频。
- 无音轨：按片段时长生成静音轨。

所有视频和音频片段分别规范化后用 concat 合并，保证时间线长度一致。

## 字幕策略

- `none`：不生成字幕输入，不烧录。
- `en`：使用 `Dialogue.text`。
- `bilingual`：英文下一行使用 `Dialogue.translation_zh`；中文为空时只显示英文。

字幕内容和字幕时间轴分开处理，中英双语共用同一条 Dialogue 时间轴：

- `start_time + end_time` 都存在时视为人工时间码，原样采用；系统不擅自缩短。
- 只有 `start_time` 时，从该时刻开始按英文原文阅读量计算结束时间。
- 没有人工时间码时，先用片段偏移和 `beat_id` 定位候选时间窗；同一时间窗内的多句对白按
  `sequence_order` 均分位置。缺失或失效的 `beat_id` 统一回退到整个片段时间窗，避免各自覆盖整段。
- 均分得到的时间窗只负责定位，不再等于字幕存活时长。实际存活时间按英文原文估算：
  基础停留 `0.5s`，英文约 `2.5 词/s`、中文约 `5 字/s`，最终限制在 `1.5–4.0s`，且不得越过
  当前时间窗；时间窗尾部默认保留最多 `0.15s` 空白。
- 双语模式只改变渲染内容，不延长时间，因此同一句对白在英文和双语导出中的出现、消失时刻一致。

后台导出在存在字幕且 ASR 已配置时，优先执行真实语音对齐：

1. 对每个包含未定时 Dialogue 的已采用视频提取 16 kHz 单声道 WAV。
2. 优先读取 ASR 的逐词或分段时间戳。网关只支持纯文本时，FFmpeg 先检测静音边界并切出短语音区间，
   逐段调用 ASR，再按识别 token 在各区间内插值得到候选词窗。
3. 按 `sequence_order` 对剧本英文和识别 token 做单调匹配，禁止后一句抢占前一句的语音。
4. 匹配成功的首尾 token 决定字幕时间，并添加少量入场/退场缓冲；片段局部时间再加累计片段偏移，
   转为最终成片时间。
5. 人工 `start_time` 仍拥有最高优先级；ASR 低置信度、无时间戳、无音轨或调用失败时，仅对应对白
   回退到上述阅读时长规则，导出本身继续执行。

ASR 识别结果只做时间定位，不能覆盖已确认字幕文本。中英双语继续共用英文对白的同一时间轴。
导出 manifest 必须记录每条 cue 的 `manual / asr / heuristic` 来源、ASR 匹配数量和降级原因，
以便排查字幕同步问题。

字幕只在导出时渲染，不创建独立字幕资产，也不改变视频模型 Prompt 中“画面禁止文字”的约束。
字幕先使用 Pillow 渲染为透明 PNG，再由 FFmpeg 按时间窗叠加，因此中文字形由
Pillow 字体决定，不依赖 FFmpeg/libass 的隐式字体回退。

- 默认字体必须覆盖当前字幕的全部字形；容器使用 Noto Sans CJK，macOS 使用系统中文字体。
- 可通过 `SUBTITLE_FONT_PATH` 显式指定 `.ttf / .ttc / .otf` 文件。
- 显式字体缺失或不覆盖字幕字形时，导出必须失败并给出原因，不允许静默产生方框字幕。

## 追溯

最终资产 manifest 保存片段 ID、片段版本、时长、是否存在原生音轨、补静音策略、字幕模式和 Dialogue ID。

## 执行、恢复与取消

- 导出与视频截帧共用单并发 `media` 任务通道；FFmpeg 运行期间不持有数据库事务。
- 子进程使用可轮询的 `Popen` 执行。收到取消请求时终止进程、清理任务临时文件并进入 `cancelled`。
- 输出文件以任务 ID 命名并通过 `MediaStore` 落盘；进程崩溃后可从冻结快照重跑，不会重复调用付费 Provider。
- 只有 FFmpeg 成功且媒体已落盘后，才在短事务中创建 `final_export` Asset、Export 审计并完成任务。
- 同一项目同时只允许一个活动导出任务；`Idempotency-Key` 可返回原任务，失败或取消任务可使用原快照人工重试。
