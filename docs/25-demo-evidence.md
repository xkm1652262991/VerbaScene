# Demo 与验证证据

本文用于区分“代码存在”“测试通过”“真实模型生成过”和“产品合同已验收”。它也是 README、简历和作品集陈述的事实边界。

## 证据等级

| 等级 | 含义 | 能证明什么 |
| --- | --- | --- |
| 定向测试 | Mock、领域服务或合同测试通过 | 代码合同与失败分支符合预期 |
| 全量测试 | 当前提交的完整自动化测试通过 | 已覆盖范围内未发现回归 |
| 只读连通 | 健康检查、模型列表或配置校验成功 | 外部服务可访问，不代表能生成 |
| 真实生成 | 真实 Provider 返回可解码媒体 | 单次模型调用和媒体落盘有效 |
| 完整成片验收 | 当前产品合同下从输入到导出完成 | 工作台主链路、返工和导出可用 |

报告结果时必须使用对应术语，不能把前一级证据描述成后一级结论。

## 下一份可公开验收包

建议使用原创角色制作一条 60–90 秒样片，并保存以下证据：

1. 输入创意、结构化剧本和最终 Dialogue。
2. 已采用的角色、场景参考图版本。
3. Shot 列表、内部节拍、最终视频 Prompt 和引用资产快照。
4. 每个 Provider 任务的模型、耗时、重试次数、失败原因和成本。
5. 最终导出媒体的 ffprobe 信息及字幕模式。
6. 至少一次局部返工，证明无关片段没有被重新生成。
7. 2–3 分钟无剪辑工作台录屏，展示创建、采用版本、重生成和导出。

完成后，再记录可量化结果，例如生成成功率、人工干预次数、总耗时和单集成本；没有原始记录时不填写估算数字。
