# Demo 与验证证据

本文用于区分“代码存在”“测试通过”“真实模型生成过”和“产品合同已验收”。它也是 README、简历和作品集陈述的事实边界。

## 证据等级

| 等级 | 含义 | 能证明什么 |
| --- | --- | --- |
| 定向测试 | Mock、领域服务或合同测试通过 | 代码合同与失败分支符合预期 |
| 全量测试 | 当前提交的完整自动化测试通过 | 已覆盖范围内未发现回归 |
| 只读连通 | 健康检查、模型列表或配置校验成功 | 外部服务可访问，不代表能生成 |
| 真实生成 | 真实 Provider 返回可解码媒体 | 单次模型调用和媒体落盘有效 |
| 完整成片验收 | 当前产品合同下从输入到导出完成 | 工作台主链路、返工和导出可用 |

报告结果时必须使用对应术语，不能把前一级证据描述成后一级结论。

- 成片时长：123 秒；480p 请求，最终导出 854×480，H.264 + AAC。
- 复用 3 张参考图，9 个剧情段全部通过 Seedance 2.0 重新生成，共 10 次生成请求。
- 每次请求使用 `duration=-1`；项目不设置全片目标时长，按返回片段的实际长度合成。
- 原生音轨，10 条英文对白完成 ASR 核对与字幕定位，无回退项；三种发布视频完成解码检查。
- 本次跳过 Reflexion；旧批次保留。可证明本轮参考图消费、智能时长、原生音频与成片导出的真实结果。

### 送你一个月亮 · MiniMax H3 历史版本

- 成片时长：99.58 秒，16:9，854×480，H.264 + AAC。
- 12 个片段、3 张角色与场景参考图、10 条英文对白。
- 真实模型：Qwen Image 3.0 参考图、MiniMax H3 R2V 原生音频视频。
- 视频生成请求 13 次，第 02 段单独重生成 1 次；部分片段经过定向剪辑与构图调整，原始版本保留。
- 英文字幕通过 ASR 与 VAD 定位，10 条均对齐、无回退项；无字幕版、英文字幕版和首页压缩版完整解码通过。
- 制作方式：Codex 根据已确定的 Markdown 直接编排并录入剧本与分镜，按要求跳过 Reflexion Agent。本次不构成完整自动剧本工作流或长期批量生产的验收。
- [公开样片与下载](https://github.com/xkm1652262991/VerbaScene/releases/tag/demo-a-moon-for-you-20260911)、[制作记录](demos/a-moon-for-you.md)、[原始剧本](scripts/送你一个月亮.md)。
