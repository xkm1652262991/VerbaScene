# 用户工作流

## 1. 顶层导航

```text
创建单集项目
  → 剧本
  → 资产库
  → 视频制作
  → 在视频制作页导出
```

`剧本 / 资产库 / 视频制作` 始终可点击。页面不显示阶段确认、跳过或“确认后才能继续”。

## 2. 创建项目

项目列表同时是创建首页。第一屏使用一个聚焦输入面板切换“导入剧本 / AI 生剧本”，下方直接展示最近项目；不再要求用户先进入独立的后台表单页。

### AI 生剧本

只需填写创意描述即可开始。项目名称可选，留空时从创意描述自动生成；英语等级、目标时长、动画风格和画幅收进“制作设置”，默认使用 A1、90 秒、16:9 及 480p。系统不采集受众年龄或“学习目标”。

导入已有剧本时，创建完成后必须立即在剧本工作区显示完整导入原稿，不能因为尚未生成结构化 `Script` 而显示为空。原稿可继续编辑和保存，用户再主动点击“AI 整理为结构化剧本”生成后台场景、对白和制作结构。

### 导入已有剧本

只需粘贴剧本文本或选择受支持的文本文件即可开始。项目名称可选并可从原稿标题自动生成；改编时优先保留事件、角色关系、因果和对白意图，再适配为动画英语短剧。

## 3. 剧本页

- 主区只展示可读剧本，不默认暴露生产场景卡、角色进出场状态、连续性字段或全局对白表单。
- 结构化场景继续在后台保存可见动作、场景连续性、角色、道具和音效提示，供资产提取、片段拆解和 Prompt 编译使用。
- 英文对白、可选中文释义、说话人、情绪、节拍和音效提示在对应视频片段中编辑；字幕导出仍读取结构化 `Dialogue`，不从最终 Prompt 反向解析。
- 保存上游内容不会删除已有图片或视频，只会把相关视频 Prompt 标记为可能过期。

## 4. 资产库

- 角色、场景、道具按目录展示。
- 每个实体包含 `base` 基础形象和带稳定键的剧情状态变体。
- 角色和场景的每个变体独立保存图片 Prompt、当前版本、历史版本、候选和出现位置。
- 道具默认只保存名称、状态、剧情作用和出现位置，不进入默认资产图生成。
- 模型输出先成为候选，用户采用一个版本后它才成为当前版本；采用不是阶段门禁。

## 5. 视频制作

小云雀式工作台布局：

- 左侧：本集与全局资产引用。
- 中间：实际发送的视频 Prompt，可编辑、保存、预览重新编译结果。
- 右侧：首帧或视频预览、生成候选、下载和片段级重新生成。
- 下方：内部镜头节拍、对白/字幕稿、音效提示、片段时间轴和版本历史。

用户可以继续编辑其他片段；只有同一资源已有活动任务时拒绝重复提交。
首帧生成和首帧引用是两个独立动作：生成首帧不会自动把它用于视频；用户必须明确点击“使用首帧”，也可以随时取消并恢复为角色/场景参考图 + 文本 Prompt。

## 6. 导出

导出弹窗列出本次采用的片段版本，并选择：

- `none`：默认，不烧字幕。
- `en`：英文字幕。
- `bilingual`：英文和中文释义。

导出直接拼接片段并保留原生音轨。没有音轨的片段补静音，保证时间线稳定。
