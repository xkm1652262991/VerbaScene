# 《送你一个月亮》制作记录

小狐狸想把月亮装进罐子，作为生日礼物送给小兔。它忙着追逐水里的倒影，却忘了陪伴等待自己的朋友。

这部原创动画样片来自[完整剧本](../scripts/送你一个月亮.md)，用于展示 VerbaScene 的参考资产、视频生成和成片导出流程。

成片时长 **99.58 秒**，16:9，854×480，H.264 视频与 AAC 立体声音轨。提供英文字幕版、无字幕原片以及独立 SRT。

本次生成 3 张参考图，执行 13 次视频生成请求，采用 12 个片段。10 条英文对白完成 ASR 与 VAD 定位，字幕对齐无回退项；两种成片与首页压缩版均通过完整解码检查。字幕开场、最长句、结尾及关键剪出点的画面已检查。

## 本次制作方法

1. 将已确定的 Markdown 剧本整理为结构化剧情、角色、场景、道具和对白。
2. 由 Codex 直接编排 12 个视频片段，共计划 110 秒，保留剧本中的 10 条英文对白。
3. 使用 Qwen Image 3.0 生成狐狸、兔子和月夜池塘的 3 张参考图。
4. 将角色与场景参考图以及含英文对白、音效的 Prompt 送入 MiniMax H3 R2V，生成视频与原生音轨。
5. 检查片段抽帧和实际语音，采用视频版本，再通过工作台的 FFmpeg 导出流程合成。

本次按制作要求跳过工作流中的 Reflexion Agent；Codex 将结构化剧本和镜头作为可编辑稿录入。对白与音效都来自视频模型的原生音轨。

## 定向返工与剪辑

- 第 02 段首版拿罐时短暂出现重复罐子，调整为狐狸开场已经捧着罐子，再单独重生成。
- 第 02 段返回的视频实际长于请求时长；最终保留 9.4 秒，让最后一个词的尾音完整结束。
- 第 04 段在第 6 秒剪出，避开生成画面提前揭示罐中月亮的问题。
- 第 05 段保留原片 3–9 秒，移除两处剧本外发声。
- 第 06 段重构图为小兔特写，保留原生音轨，让狐狸画外回答。原片中错误的罐内物品不进入成片。
- 第 10 段保留后半段近景和完整的两句原定对白，移除前半段重复与不清晰的发声。

原始生成版本仍保留在工作台，剪辑版本作为新资产采用。制作记录区分生成次数和后期剪辑，不将剪辑操作计为新的模型生成。
