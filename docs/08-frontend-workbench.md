# 前端工作台设计与当前实现

## 1. 定位

前端是动画启蒙英语短剧的内部生产工作台，重点是直接编辑、资产引用、候选版本和可追溯生成，不是营销站点。当前技术栈为 React 18、TypeScript 和 Vite。

## 2. 路由方式

当前没有使用 React Router，`App.tsx` 直接解析 URL Hash：

| 路由 | 页面 |
| --- | --- |
| `#/projects` | 项目列表 |
| `#/projects/new` | 新建项目 |
| `#/projects/{project_id}` | 片段中心导演台，默认选择第一个片段 |
| `#/projects/{project_id}/shots/{shot_id}` | 导演台并恢复指定片段 |
| `#/projects/{project_id}/assets/generate` | 剧本完成后的集中资产图生成页 |
| `#/projects/{project_id}/assets` | 兼容旧入口，进入同一项目导演台 |
| `#/projects/{project_id}/files` | 兼容旧入口，进入同一项目导演台 |
| `#/tasks` | 任务中心 |
| `#/models` | 运行模型与 Agent 覆盖配置 |

项目列表卡片把“进入项目”和“删除”作为两个独立操作，避免整张链接卡片内嵌按钮造成点击穿透。删除时前端先读取项目关联记录、本地文件数量/体积和运行中任务，再要求用户完整输入项目名称；成功后只从当前列表移除该项目并展示数据库与本地媒体处理结果。

## 3. 项目工作台

`ProjectDetailPage` 是以当前视频片段为中心的沉浸式导演台。有片段时默认进入视频制作，没有片段时显示剧本引导。项目路由不显示全局侧栏、阶段进度条或“当前阶段”提示。

制作页常驻四个区域：

- 左侧资产栏：真实缩略图、分类、搜索和引用操作；“当前片段”由中间引用资产条表达，不重复占用筛选入口。
- 中间脚本画布：当前片段的场景、内部镜头节拍、对白、音效和高级 Prompt。
- 右侧预览栏：当前视频/首帧、候选、历史版本及片段级操作。
- 底部片段时间轴：缩略图、时长、版本和生成状态，是切换片段的主入口。

剧本和完整资产管理以宽抽屉覆盖在导演台上，关闭抽屉后保持原片段、草稿和滚动位置。运行记录同样使用轻量抽屉。

首次生产流程中的“生成资产图”不是资产库管理动作。剧本生成或整理完成后直接进入
独立的集中资产图生成页：先提取角色、场景和道具结构，再统一生成与采用角色、场景
基础图，最后进入视频制作。资产库抽屉只负责后续查看、编辑 Prompt、状态变体、
单项重生成和历史版本管理。

页面首次加载优先请求 `GET /api/projects/{project_id}/workbench`，一次获得项目设置、章节、剧本、实体、片段、资产、候选、导出、质量检查和运行记录。响应不再包含阶段门禁。

### 3.1 视觉与布局约束

当前视觉语言参考影视制片后台，而不是通用管理面板：白色画布、浅灰工作面、深色正文、低饱和紫色主操作和绿色完成状态。缩略图与可读脚本优先，媒体预览和 Prompt 代码块保留深色以维持内容对比。

项目工作台以 `100vh` 为布局边界，各栏独立滚动，底部时间轴始终可见。项目抬头只保留返回、项目设置摘要、模型能力、剧本/资产入口、运行记录和导出。项目路由隐藏全局管理导航，避免“全局导航 + 阶段导航 + 当前阶段说明”的重复堆叠。

导演台布局和交互样式位于 `apps/web/src/styles/global.css`，通用页面的编辑视觉仍由 `editorial.css` 补充。新增组件不应重新引入常驻左侧阶段栏、层层叠加的白色卡片阴影或每个辅助信息都默认展开的布局。

## 4. 工作区交互

视频制作是项目的默认工作面；剧本和资产库是随时可打开的管理抽屉。

- 所有工作区始终可进入。
- 不展示“确认后才能继续”“跳过阶段”或阶段级审批按钮。
- 上游内容修改后，相关资产、Prompt 或视频以“可能过期”提示，不自动删除、不阻止查看。
- 无片段项目的主操作必须依据当前数据切换：没有结构化剧本时引导打开剧本；已有剧本后进入集中资产图生成页，在该页完成实体提取、角色/场景生图与采用，再生成片段方案。前端不得展示必然被后端前置条件拒绝的主按钮。
- “采用版本”只改变当前选择，不推进或解锁流程。
- 同一资源正在生成时禁用该资源的重复提交，其他操作继续可用。

## 5. 候选与正式资产

图片和视频生成只调用候选接口：

```text
generate-candidates
  -> CandidateReviewList
  -> promote / reject
  -> 正式 Asset
  -> select
```

资产管理页负责跨阶段查看正式资产、候选、版本、来源任务和引用对象。文件管理页更偏运维排查，区分可预览 URL、data URI、内部路径和不可预览记录。

## 6. 任务状态的真实边界

导演台在动作完成后重新请求整个 workbench；运行中任务通过“运行记录”和任务中心查看。当前导演台不建立 SSE 连接，也不展示前端伪造的百分比进度。长视频任务的最终状态以任务记录和 Provider 回传为准。

## 7. 页面能力

### 7.1 创建与剧本

- 项目列表同时承担创建首页：顶部是聚焦的短剧输入面板，下面紧接“我的项目”，不再用“项目列表 → 新建项目 → 后台表单”三段跳转。
- 输入面板提供“导入剧本”和“AI 生剧本”两个入口，默认打开导入剧本；切换入口只显示当前方式需要的正文输入。
- 项目名称改为可选，留空时前端从剧本标题或创意描述自动生成。英语级别、动画风格、目标时长、画幅和分辨率收进“制作设置”折叠区；默认 A1、16:9、854×480（480p）、90 秒。
- 导入入口支持直接粘贴正文，并明确展示当前真正支持的本地文本文件格式；不宣称尚未实现的 DOCX/PDF 解析能力。
- 创建首页不显示或提交受众年龄、学习目标字段。
- “导入已有剧本”创建成功后，剧本抽屉立即显示 `Chapter.source_text` 的完整原稿；“AI 生剧本”在生成前显示 `Chapter.outline`。两者均可编辑并通过章节保存接口更新，不能以“尚未生成结构化剧本”替代用户已经提交的内容。
- 导入原稿尚未结构化时，主操作命名为“AI 整理为结构化剧本”；结构化结果生成后，剧本抽屉只展示可读正文，不展开后台生产场景卡。
- 默认值为 A1、16:9、854×480（480p）、无字幕。
- 项目工作台保留未提交输入到 `localStorage`。
- 剧本抽屉默认只呈现可读剧本；生产场景、角色进出场状态、连续性和道具字段作为后台数据，不进入常规编辑界面。
- 剧本生成或整理成功后自动跳转到集中资产图生成页；已有剧本时同时提供明确的“下一步：生成资产图”按钮。
- 全局对白表单从剧本抽屉移除。英文对白、可选中文释义、说话人、情绪和音效提示在对应片段编辑器维护，导出字幕继续使用独立 `Dialogue` 数据。

### 7.2 实体与分镜

- 角色、场景、道具生成和编辑。
- 集中资产图生成页同时展示全部角色和场景的采用状态，提供统一图片模型选择、批量生成角色/场景候选和逐项采用；道具只展示为结构化信息，不进入默认生图队列。
- 资产设定采用与分镜一致的“资产目录 + 单项编辑器”：角色、场景、道具合并进左侧目录，右侧只展示当前资产表单；切换资产时保留未保存草稿，窄屏端目录改为横向滚动，禁止同时平铺全部资产表单。
- 角色资产只维护一个 `base` 多视角设定图槽位，不为尴尬、道歉、用力推车等剧情状态生成独立图片。这些状态作为可读文本展示，并在对应片段中编译进视频 Prompt。
- 场景资产仍可区分基础形象、持续视觉状态变体和同一形象的重生成版本，并展示稳定变体键、图片 Prompt、当前版本、历史版本和出现位置。
- Patch Impact 面板支持变更影响预演，但不会自动执行下游补丁。

### 7.3 视频制作

- 左侧资产栏只提供“角色、场景、道具、素材”四类筛选和搜索，默认打开角色。资产卡以缩略图、名称、状态变体和版本呈现，支持点击或拖拽绑定到当前片段。
- 中间引用资产条是当前片段引用的唯一快捷入口。点击已有引用可更换同类实体、状态变体或已采用的精确历史版本，也可直接移除；内部保存资产 ID，不按名称猜测。默认资产图和视频引用只包含角色与场景；道具只显示结构化剧情数据。
- 中间默认显示可读片段脚本，资产以内嵌标签呈现。编辑模式一次保存镜头节拍、对白/字幕稿和音效提示；逐键输入不得触发 API。
- 内部镜头编辑器只维护剧情推进、镜头语言、动作、对白和音效，不展示或编辑单镜头秒数。未生成片段在时间轴显示“智能时长”，采用视频后显示实际秒数。
- 底部卡片表示一次可生成的连续叙事片段，不表示单个 2–3 秒摄影镜头；片段内部的 2–4 个镜头在中间画布按顺序展开。
- 最终 Prompt 收进高级区；预览展示实际会发送的素材序号。首帧默认不发送，用户在右侧明确点击“使用首帧”后才进入列表；取消后立即恢复无首帧模式。`Shot.video_prompt` 仍是实际发送稿，过期提示不会覆盖人工编辑内容。
- 右侧集中预览当前视频、首帧、候选和历史版本，并提供生成、采用、拒绝、下载、截帧和局部重生成。
- 底部时间轴显示缩略图、时长、版本和状态。点击后资产、脚本、预览、候选和 URL 同步切换。
- 切换片段时若有未保存草稿，必须允许保存并切换、放弃或取消。
- 提供重新编译 Prompt、生成候选、采用版本、下载片段、截帧和局部重生成。
- 模型栏只显示图片和视频 Provider，并展示画幅、分辨率、风格、参考输入和原生音频能力。
- 视频 Provider 支持 `smart_duration` 时默认使用智能时长并提示生成后按实际时长计费和合成；只有人工选择固定时长时，才按 `min_duration_sec / max_duration_sec` 禁用越界提交。不得静默缩短。
- 导出是视频制作页内操作。弹窗列出将采用的片段版本，并选择 `none`、`en` 或 `bilingual`；默认 `none`。
- 产品中不再出现 TTS、音色、单句重配音、独立音效生成或声音阶段。

## 8. 全局管理页

- 项目列表：展示生产状态并提供项目级删除入口；活动任务/阶段运行会阻止删除，数据库记录删除后本地媒体进入项目回收目录。当前没有一键恢复或清空回收目录 UI。
- 任务中心：分页、按状态/项目筛选，查看失败原因和上下文跳转；当前没有任务重试按钮和真实后台取消。
- 模型管理：左侧切换文本、图像、视频三个运行槽位，右侧只编辑当前槽位；可保存 Provider、模型、端点、密钥来源和受支持参数。密钥可以引用环境变量，也可以通过密码框直接提交到后端本机私有文件；读取页面不会回显。保存后当前 API 进程立即生效。视频槽位展示原生音频、图片/视频/音频参考、多参考输入、智能时长、固定时长范围和支持分辨率。Agent 模型覆盖作为独立入口保留，可新增、编辑、启停指定文本 Agent 的配置，优先级高于全局文本模型。
- Prompt 管理：管理 `PromptVersion`，支持内置 AVD Prompt 包写入/启用。

## 9. 当前风险

- `workbench` 聚合响应可能包含大体积 base64 资产，项目增大后加载成本会迅速上升。
- Hash 路由、单大页状态和手写 API 类型在规模扩大后维护成本较高。
- SSE 是心跳轮询替代方案，不是真正的实时事件架构。
- 没有登录、权限和媒体访问控制。
- 前端本地模拟进度无法反映 Provider 卡死、远端排队或真实百分比。

后续优化顺序应是：轻量 workbench + 真实任务事件 → 后台任务语义 → 鉴权与访问控制 → 再考虑路由/状态管理框架升级。
