# 产品需求文档

## 1. 产品概述

本项目是面向内部内容生产的动画风格启蒙英语短剧工作台。它把一段创意描述或一份已有剧本，转换为可编辑的英语剧本、结构化资产、带原生对白与音效的视频片段，以及可选择字幕模式的单集成片。

本轮只支持单集项目。顶层工作流固定为：

```text
剧本 -> 资产库 -> 视频制作
```

三个工作区可自由进入。系统不使用阶段确认门禁阻止浏览或编辑；人工控制通过编辑、选择当前资产版本、采用视频候选和主动重新生成实现。

## 2. 目标用户

### 2.1 MVP 用户

- 内部内容生产人员
- 熟悉动画短剧制作流程的运营人员
- 需要制作儿童启蒙英语内容的创作者

### 2.2 后续用户

- 个人短视频运营者
- 小型内容工作室
- 儿童英语内容创作者
- AI 视频代运营团队

## 3. 核心价值

- 将创意或已有剧本快速改编为 A1 英语短剧。
- 管理角色、场景参考图和结构化道具数据。
- 通过基础形象、剧情状态变体和参考图提高角色一致性。
- 在一个小云雀式工作台中编辑片段 Prompt、引用资产、预览候选和管理版本。
- 让支持原生音频的视频模型直接生成对白与音效，避免独立 TTS 和音效混音链路。
- 在导出时按需烧录英文或中英双语字幕。
- 保留 Provider Adapter 能力，便于切换不同模型供应商。

## 4. MVP 范围

### 4.1 必须支持

- 通过“AI 生剧本”或“导入剧本”创建单集项目。
- 设置英语级别、动画风格、目标时长、画幅和分辨率；产品不采集或限制受众年龄。
- AI 创意模式根据创意描述生成剧本；导入模式优先忠实保留已有剧本。
- 生成和编辑中文制作描述、英文对白、可选中文释义、情绪和结构化音效提示。
- 自动提取角色、场景、道具。
- 编辑角色、场景、道具的基础形象和状态变体。
- 默认只为角色和场景生成参考图，并管理当前版本、历史版本和出现位置；道具保留结构化描述，不默认生成独立图片。
- 把单集拆成可独立生成的视频片段；每个片段包含多个内部镜头节拍。
- 把场景、资产引用、镜头节拍、英文对白、说话人、情绪和音效提示编译为可编辑的最终视频 Prompt；片段首帧只有在用户明确启用时才作为视频输入。
- 生成、预览、采用、下载、截帧和局部重生成视频候选。
- 使用 FFmpeg 拼接采用的视频版本，并保留片段的原生音轨。
- 对无音轨片段补静音，保证时间线稳定。
- 导出无字幕、英文字幕或中英双语字幕的成片；默认无字幕。
- 导出最终视频。

### 4.2 暂不支持

- 完整商业化计费。
- 多集项目与分集管理。
- 多租户团队协作。
- 会员套餐和支付。
- 片头片尾。
- 封面生成。
- 背景音乐自动生成。
- 角色 LoRA 训练。
- 高级视频时间线编辑器。
- 独立 TTS、音色管理、单句重配音和独立音效生成。
- Seedance、Seedream 的真实 Provider Adapter；本轮只定义能力合同。
- 移动端优先适配。

### 4.3 当前实现缺口

以下能力属于后续工程范围：

- Seedance/Seedream Provider 的真实请求、轮询、下载和计费适配。
- Celery/LangGraph 异步执行尚未落地，生成和合成仍由主 API 同步执行。
- 用户鉴权、权限和媒体访问控制尚未落地，只适合可信内网试用。

## 5. 内容规格

- 内容方向：动画风格启蒙英语短剧。
- 受众年龄：不限制，不作为项目字段或生成约束。
- 默认英语级别：CEFR A1。
- 输入：AI 创意描述或已有剧本。
- 输出：单集动画短剧。
- 默认比例与分辨率：16:9、854×480（480p）。
- 可选比例与分辨率：9:16、480×854。
- 时长：1-3 分钟。
- 对白：英文必填，中文释义可选。
- 音频：由视频模型在片段内原生生成对白和音效。
- 字幕：默认不烧录；导出时可选择英文或中英双语。

## 6. 关键体验原则

- 用户可随时在剧本、资产库和视频制作之间切换。
- 每个生成结果都应支持单项重生成。
- 生成失败时应显示原因和后续处理入口；图片/视频失败默认进入手动重生成，不自动重试。
- 不满意的资源不应覆盖旧版本。
- 上游变化只标记下游 Prompt 或产物“可能过期”，不删除、不锁页、不自动覆盖人工编辑稿。
- 只有用户点击“重新编译 Prompt”时才覆盖当前 `Shot.video_prompt`。
- Prompt、引用资产、输入指纹、Provider、模型和任务状态必须可追溯。
- 运行中的同资源任务要防止重复提交，但不能阻止用户操作其他页面或其他资源。

## 7. 成功标准

MVP 成功标准：

- 用户能通过 AI 创意或导入剧本完成一条 1–3 分钟启蒙英语短剧。
- A1 英文对白能绑定到具体片段和内部镜头节拍，中文释义允许为空。
- 视频最终 Prompt 精确包含对白、说话人、情绪和音效提示，并禁止画面生成字幕或可读文字。
- 用户无需确认前一阶段即可浏览、编辑或生成其他工作区内容。
- 最终视频能稳定导出为 854×480 或 480×854 MP4。
- 多个带原生音轨和无音轨片段可稳定拼接。
- 同一组片段可分别导出无字幕、英文字幕和双语字幕版本。
- 至少支持一种 LLM、一种图片 Provider 和一种具备原生音频能力声明的视频 Provider；验收默认使用 Mock。

## 8. 后续商业化预留

MVP 不实现商业化，但数据结构和服务层预留：

- 用户 ID。
- 工作空间 ID。
- Provider 配置归属。
- 任务成本字段。
- 生成额度字段。
- 导出水印配置。
- 项目权限字段。
